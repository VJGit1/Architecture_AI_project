Planner Controls

Controls:
- Left Mouse: Orbit/Rotate
- Right Mouse: Pan/Move View
- Scroll Wheel: Zoom
- Click Object: Select
Transform Keys (when selected):
- T: Translate (Move)
- R: Rotate
- S: Scale (Resize)
Room Features:
- Add Room: Creates room with floor + 4 walls
- Scale: Resize room dimensions
- Real-time: See dimensions while scaling
Door Features:
- Click Wall: Select wall for door placement
- Add Door: Create door on selected wall
- Click Door: Edit door properties
- Walls Only: Doors can only be placed on walls
